PART A — ONE-TIME AZURE SETUP (Portal Clicks)
================================================================================

A1 — Create Resource Group
---------------------------
1. Go to https://portal.azure.com
2. Search bar → type "Resource groups" → click it
3. Click + Create
4. Fill:
   - Subscription: your subscription
   - Resource group: eshopping-dev-rg
   - Region: East US
5. Click Review + create → Create

--------------------------------------------------------------------------------

A2 — Create Azure App Service Plan (shared by all services)
------------------------------------------------------------
1. Search → "App Service plans" → click it
2. Click + Create
3. Fill:
   - Resource group: eshopping-dev-rg
   - Name: eshopping-plan-b1
   - OS: Linux
   - Region: East US
   - Pricing tier: click "Explore pricing plans" → Basic B1 → Select
4. Review + create → Create

--------------------------------------------------------------------------------

A3 — Create 6 App Services (one per microservice)
--------------------------------------------------
Repeat these steps 6 times using the table below:

1. Search → "App Services" → + Create → Web App
2. Fill:
   - Resource group: eshopping-dev-rg
   - Name: (from table)
   - Publish: Code
   - Runtime stack: .NET 8 (LTS)
   - OS: Linux
   - Region: East US
   - Linux Plan: eshopping-plan-b1
3. Click Review + create → Create

App Services to create:
  1. eshopping-catalog-dev   → Catalog.API
  2. eshopping-basket-dev    → Basket.API
  3. eshopping-discount-dev  → Discount.API
  4. eshopping-ordering-dev  → Ordering.API
  5. eshopping-identity-dev  → EShopping.Identity
  6. eshopping-gateway-dev   → Ocelot.ApiGateway

--------------------------------------------------------------------------------

A4 — Create Azure Database for MySQL
--------------------------------------
1. Search → "Azure Database for MySQL flexible servers" → + Create → Flexible server
2. Fill:
   - Resource group: eshopping-dev-rg
   - Server name: eshopping-mysql-dev  (must be globally unique)
   - Region: East US
   - MySQL version: 8.0
   - Workload type: For development or hobby projects
   - Click Configure server → Burstable → B1ms → Save
   - Admin username: mysqladmin
   - Password: (strong password, save it)
3. Click Next: Networking:
   - Connectivity: Public access
   - Check: Allow public access from any Azure service within Azure
4. Review + create → Create  (~5 min)

After creation — create 4 databases:
1. Open MySQL resource → left menu → Databases
2. Click + Add → Name: CatalogDb → Save
3. Repeat for: BasketDb, DiscountDb, OrderDb

--------------------------------------------------------------------------------

A5 — Create Azure Service Bus
------------------------------
1. Search → "Service Bus" → + Create
2. Fill:
   - Resource group: eshopping-dev-rg
   - Namespace: eshopping-servicebus-dev
   - Location: East US
   - Pricing tier: Standard  (Basic doesn't support Topics — MassTransit needs them)
3. Review + create → Create

After creation — get connection string:
1. Open Service Bus resource
2. Left menu → Shared access policies → click RootManageSharedAccessKey
3. Copy Primary Connection String — save it

--------------------------------------------------------------------------------

A6 — Create Application Insights
----------------------------------
1. Search → "Application Insights" → + Create
2. Fill:
   - Resource group: eshopping-dev-rg
   - Name: eshopping-insights-dev
   - Region: East US
3. Create → open resource
4. Copy Connection String (top of Overview page) — save it

--------------------------------------------------------------------------------

PART C — CODE CHANGES IN THE PROJECT
================================================================================

C1 — EventBusSettings.cs
  File: Infrastructure/EventBus.Messages/Common/EventBusSettings.cs
  Change:
    Add ServiceBusConnection property alongside existing HostAddress.

  BEFORE:
    public class EventBusSettings
    {
        public string HostAddress { get; set; } = "amqp://guest:guest@localhost:5672";
    }

  AFTER:
    public class EventBusSettings
    {
        public string HostAddress { get; set; } = string.Empty;           // RabbitMQ (unused)
        public string ServiceBusConnection { get; set; } = string.Empty;  // Azure Service Bus
    }

--------------------------------------------------------------------------------

C2 — Basket.API.csproj
  File: Services/Basket/Basket.API/Basket.API.csproj
  Remove:  <PackageReference Include="MassTransit.RabbitMQ" Version="8.3.6" />
  Add:     <PackageReference Include="MassTransit.Azure.ServiceBus.Core" Version="8.3.6" />

--------------------------------------------------------------------------------

C3 — Ordering.API.csproj
  File: Services/Ordering/Ordering.API/Ordering.API.csproj
  Same swap as C2.

--------------------------------------------------------------------------------

C4 — Basket.API/Startup.cs
  File: Services/Basket/Basket.API/Startup.cs
  Replace UsingRabbitMq block:

  BEFORE:
    config.UsingRabbitMq((ct, cfg) =>
    {
        cfg.Host(eventBusSettings!.HostAddress);
        cfg.UseMessageRetry(retryConfig =>
        {
            retryConfig.Interval(3, TimeSpan.FromSeconds(5));
        });
    });

  AFTER:
    config.UsingAzureServiceBus((ct, cfg) =>
    {
        cfg.Host(eventBusSettings!.ServiceBusConnection);
        cfg.UseMessageRetry(retryConfig =>
        {
            retryConfig.Interval(3, TimeSpan.FromSeconds(5));
        });
    });

--------------------------------------------------------------------------------

C5 — Ordering.API/Startup.cs
  File: Services/Ordering/Ordering.API/Startup.cs
  Replace UsingRabbitMq block:

  BEFORE:
    config.UsingRabbitMq((ctx, cfg) =>
    {
        cfg.Host(eventBusSettings!.HostAddress);
        ...receive endpoints...
    });

  AFTER:
    config.UsingAzureServiceBus((ctx, cfg) =>
    {
        cfg.Host(eventBusSettings!.ServiceBusConnection);
        cfg.UseMessageRetry(retryConfig =>
        {
            retryConfig.Interval(3, TimeSpan.FromSeconds(5));
        });
        cfg.ReceiveEndpoint(EventBusConstants.BasketCheckoutQueue, c =>
        {
            c.ConfigureConsumer<BasketOrderingConsumer>(ctx);
        });
        cfg.ReceiveEndpoint(EventBusConstants.BasketCheckoutQueueV2, c =>
        {
            c.ConfigureConsumer<BasketOrderingConsumerV2>(ctx);
        });
    });

D1 — .azuredevops/templates/build-publish.yml
----------------------------------------------
parameters:
  - name: projectPath
    type: string
  - name: artifactName
    type: string

steps:
  - task: UseDotNet@2
    displayName: 'Use .NET 8'
    inputs:
      packageType: sdk
      version: '8.0.x'

  - task: DotNetCoreCLI@2
    displayName: 'Restore'
    inputs:
      command: restore
      projects: '${{ parameters.projectPath }}'

  - task: DotNetCoreCLI@2
    displayName: 'Build'
    inputs:
      command: build
      projects: '${{ parameters.projectPath }}'
      arguments: '--configuration Release --no-restore'

  - task: DotNetCoreCLI@2
    displayName: 'Publish'
    inputs:
      command: publish
      publishWebProjects: false
      projects: '${{ parameters.projectPath }}'
      arguments: '--configuration Release --output $(Build.ArtifactStagingDirectory)/${{ parameters.artifactName }}'
      zipAfterPublish: true

  - task: PublishBuildArtifacts@1
    displayName: 'Upload Artifact'
    inputs:
      PathtoPublish: '$(Build.ArtifactStagingDirectory)/${{ parameters.artifactName }}'
      ArtifactName: '${{ parameters.artifactName }}'

--------------------------------------------------------------------------------

D2 — .azuredevops/templates/deploy-appservice.yml
---------------------------------------------------
parameters:
  - name: artifactName
    type: string
  - name: appServiceName
    type: string
  - name: azureSubscription
    type: string

steps:
  - task: DownloadBuildArtifacts@1
    displayName: 'Download Artifact'
    inputs:
      buildType: current
      artifactName: '${{ parameters.artifactName }}'
      downloadPath: '$(System.ArtifactsDirectory)'

  - task: AzureRmWebAppDeployment@4
    displayName: 'Deploy to App Service'
    inputs:
      ConnectionType: AzureRM
      azureSubscription: '${{ parameters.azureSubscription }}'
      appType: webAppLinux
      WebAppName: '${{ parameters.appServiceName }}'
      packageForLinux: '$(System.ArtifactsDirectory)/${{ parameters.artifactName }}/*.zip'
      RuntimeStack: 'DOTNETCORE|8.0'

D4 — Example pipeline (catalog-pipeline.yml — same structure for all 6)

trigger:
  branches:
    include: [main]
  paths:
    include:
      - Services/Catalog/**
      - Infrastructure/Common.Logging/**

pool:
  vmImage: ubuntu-latest

variables:
  artifactName: catalog-api
  appServiceName: eshopping-catalog-dev
  azureSubscription: azure-eshopping-dev

stages:
  - stage: Build
    displayName: Build Catalog API
    jobs:
      - job: BuildJob
        steps:
          - template: ../templates/build-publish.yml
            parameters:
              projectPath: 'Services/Catalog/Catalog.API/Catalog.API.csproj'
              artifactName: $(artifactName)

  - stage: Deploy
    displayName: Deploy Catalog API
    dependsOn: Build
    condition: succeeded()
    jobs:
      - deployment: DeployJob
        environment: dev
        strategy:
          runOnce:
            deploy:
              steps:
                - template: ../templates/deploy-appservice.yml
                  parameters:
                    artifactName: $(artifactName)
                    appServiceName: $(appServiceName)
                    azureSubscription: $(azureSubscription)
